Un petit modèle honnête sur FLEX

Prédire la constante de combustion K et le risque d'extinction d'une gouttelette à partir de ~170 essais — et savoir dire ce que le modèle ne sait pas.

Temps : ~2 hpandas · scikit-learnPrérequis : Table IX transcrite (guide 02)

1. Faut-il vraiment du ML ?

Le Guide d'équipe le rappelle : le ML est une extension, pas un prérequis. Avec ~170 lignes, on peut faire un modèle utile si on reste modeste :

  • il interpole dans la plage des essais FLEX (O₂, pression, diamètre testés) — il n'extrapole pas à la Lune ;
  • il est comparé à une baseline simple ; s'il ne la bat pas, on ne le montre pas ;
  • l'écran Simulator affiche « Model · … » et les limites.

3. Le code de départ

import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.dummy import DummyRegressor
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import KFold, cross_val_score
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder

df = pd.read_csv("data/flex/flex_table_ix.csv").dropna(subset=["burn_rate_k_mm2_s"])
X = df[["fuel", "pressure_atm", "o2_mole_fraction", "co2_mole_fraction", "initial_diameter_mm"]]
y = df["burn_rate_k_mm2_s"]

prep = ColumnTransformer([("fuel", OneHotEncoder(handle_unknown="ignore"), ["fuel"])], remainder="passthrough")
cv = KFold(n_splits=5, shuffle=True, random_state=42)
for name, model in [("baseline", DummyRegressor()), ("forest", RandomForestRegressor(n_estimators=300, random_state=42))]:
    pipe = Pipeline([("prep", prep), ("model", model)])
    mae = -cross_val_score(pipe, X, y, cv=cv, scoring="neg_mean_absolute_error")
    print(f"{name:9s} MAE = {mae.mean():.3f} ± {mae.std():.3f} mm²/s")

Pour la classification : LogisticRegression ou RandomForestClassifier, StratifiedKFold, scoring "f1", baseline DummyClassifier(strategy="most_frequent").

4. Les pièges classiques

À éviter
  • Évaluer sur les données d'entraînement : toujours de la validation croisée (5 plis).
  • Fuite d'information : ne jamais utiliser une colonne mesurée après l'essai (durée de combustion, diamètre à l'extinction) pour prédire le résultat.
  • Surapprentissage : 170 lignes, c'est peu ; préférer des modèles simples et limiter la profondeur des arbres.
  • Classes déséquilibrées : regarder la matrice de confusion, pas seulement l'exactitude.
  • Extrapolation : refuser (ou signaler) une prédiction hors des plages vues (ex. O₂ > max des essais).

5. Brancher le modèle dans l'API

  1. Script backend/pipeline/train_flex.py : entraîne, affiche les scores CV, sauvegarde avec joblib.dump(pipe, "models/flex_k.joblib") (dossier ignoré par Git ou petit fichier documenté).
