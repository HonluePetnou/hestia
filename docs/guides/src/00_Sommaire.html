Les 7 guides

01 — Science de la combustion en microgravité

Flottabilité, diffusion, loi en d², extinction, flammes froides, propagation sur solides, Lune et Mars, comment lire un rapport NTRS.

02 — Données NASA : NTRS, PSI, FLEX

Où sont les données, comment les récupérer, transcrire la Table IX, notre modèle de données, règles d'unités et de traçabilité.

03 — IA : RAG et réponses citées

Embeddings, découpage en passages, recherche pgvector, prompt « sources seulement », vérification des citations, évaluation.

04 — Backend : FastAPI + PostgreSQL

Architecture du dépôt, lancer le projet sous Windows, ajouter une route, migrations Alembic, tests, types partagés avec le front.

05 — Machine Learning sur FLEX

Quand le ML est justifié, régression de K, classification extinction, validation croisée, baseline, présentation honnête.

06 — Frontend : Next.js, design, 3D

Composants serveur/client, tokens du design Figma, données via l'API, Recharts, React Three Fiber, pièges déjà rencontrés.

07 — Pitch, démo et soumission

Scénario de démo, script vidéo 30 s, plan des 7 slides, règles du brand guide, check-list de soumission, plan B.

Décisions à prendre dès maintenant

  1. Fournisseur LLM et embeddings : OpenAI, Gemini ou Claude (Claude n'a pas d'API d'embeddings → combiner avec un autre). Voir guide 03.
  2. Taille des vecteurs (EMBEDDING_DIM) : à fixer avant l'ingestion ; la changer ensuite oblige à recréer la base.
  3. Répartition des rôles : compléter le tableau « Team » du README.
  4. CI GitHub : les exécutions échouent au démarrage ; vérifier les réglages Actions / facturation du compte.
  5. Périmètre : le Guide d'équipe conseille 2 à 3 familles d'expériences. Proposition : FLEX (gouttelettes), SAFFIRE et BASS (solides).
Règle d'or de l'équipe

Aucun chiffre sans unité ni source ; aucune réponse IA sans citation vérifiable. Une donnée manquante s'affiche « non renseigné ». C'est ce qui rend Hestia crédible devant le jury.
